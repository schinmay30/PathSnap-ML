Coordinate values were within longitude/latitude ranges, timestamps were nondecreasing with no adjacent equal or decreasing steps, and all arc endpoint IDs and route arc IDs were in range for their corresponding files.

The scan flags a time interval greater than 5 seconds as a gap for review. This threshold is an initial diagnostic choice, not an official project limit. Large gaps should be inspected before deciding how the feature pipeline or route decoder handles them. The longest interval in training is especially large and should be reviewed as a likely trip break, data anomaly, or long recording pause.

The inventory does not establish a one-to-one alignment between GPS observations and route entries. Confirm route-to-observation alignment before using the route file as per-observation labels. Use training trips for fitting and cross-validation; use student-testing trips only for development-stage comparisons. Do not use evaluator-testing data or labels during development.
